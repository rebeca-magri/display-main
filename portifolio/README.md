# 📚 Estudo de `display` no CSS

Projeto criado para estudar a propriedade `display` do CSS e entender, na prática, seus principais valores e casos de uso.

## 🎯 Objetivo

Explorar como diferentes valores de `display` alteram o comportamento, o posicionamento e a organização dos elementos HTML na página.

## 🧩 Conteúdos estudados

- `display: block`
- `display: inline`
- `display: inline-block`
- `display: flex`
- `display: grid`
- `display: none`

## 💡 Sobre o projeto

Cada exemplo demonstra uma situação prática de uso dos diferentes tipos de `display`, facilitando a comparação entre eles e ajudando a entender quando utilizar cada abordagem.

O projeto foi desenvolvido utilizando apenas **HTML e CSS**, com foco no aprendizado e na experimentação.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 🚀 Como executar

1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador:
    git clone https://github.com/rebeca-magri/display.git
3. Explore os exemplos e altere o CSS para observar os diferentes comportamentos.

## 📖 Objetivo de aprendizado

Este projeto faz parte dos meus estudos de **HTML e CSS**, com foco em compreender melhor o sistema de layout e a forma como os elementos podem ser organizados em uma página web.
